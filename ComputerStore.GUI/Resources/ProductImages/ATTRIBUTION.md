# Product image credits

The files below are photographs from Wikimedia Commons. Category and generic-CPU photographs are representative images, not proof of the exact product model. The UI labels category images as `Ảnh đại diện` and close-but-different variants as `Ảnh tham khảo`. Only SKU photographs whose model is verified are mapped as exact products. Other products can use a custom image selected by an administrator.

The distributed source image files are unmodified. The application scales them for display; it crops `product_cpu_intel_i5.jpg` only in memory, and that source is CC0. Each source page links to the applicable license and records any additional terms.
